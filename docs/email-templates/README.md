## Send them from your own address (recommended)

Supabase's built-in sender is limited to a few emails an hour and comes from a Supabase address. Send through your Resend account instead:

1. Supabase → Authentication → Emails → **SMTP Settings** → turn on **Enable custom SMTP**.
2. Fill in the fields below, then **Save**.

| Field | Value |
|---|---|
| Sender email | `notifications@usegympulseai.com` |
| Sender name | `GymPulse AI` |
| Host | `smtp.resend.com` |
| Port | `465` |
| Username | `resend` |
| Password | your Resend API key (`re_...`) |

3. Under **Rate limits**, raise the email limit, for example to 60 an hour.
