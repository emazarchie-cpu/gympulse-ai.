# Synthetic Gym Dataset

This directory contains documentation for the synthetic dataset used in the GymPulse AI project.

The dataset is generated programmatically using Python and NumPy to simulate gym membership characteristics, attendance patterns, and cancellation outcomes.

## Purpose

The dataset supports experimentation with exploratory data analysis, feature engineering, and machine learning workflows.

## Important Limitations

- All records are fictional.
- Cancellation outcomes are generated using an artificial probability rule.
- Patterns discovered in this dataset do not establish real-world relationships.
- Model performance on this dataset should not be interpreted as evidence of real-world cancellation prediction accuracy.

The generated CSV file is excluded from this repository's initial documentation. It can be added separately when appropriate.
